#  21-school: Коллекция учебных проектов

Данный репозиторий представляет собой портфолио из трех разноплановых проектов, разработанных в рамках обучения. Проекты охватывают 
**Fullstack-разработку** на Java, **автоматизацию UI-тестирования (AQA)** и создание **интерактивных frontend-симуляций** на чистом JavaScript.

## 📂 Содержание репозитория

| № | Проект | Описание | Основной стек |
|:---:|:---|:---|:---|
| **1** | [**Крестики-нолики**](./Tic-Tac-Toe/) | Многопользовательская веб-игра с авторизацией, историей матчей и AI (Minimax). Уникальное визуальное оформление. | `Java 17` `Spring Boot` `PostgreSQL` `REST API` `HTML/JS` |
| **2** | [**UI Web Testing (AQA)**](./AQA-UI-Testing/) | Проект по автоматизации UI-тестирования веб-приложения SauceDemo с использованием BDD и Page Object. | `Java 21` `JUnit 5` `Selenide` `Cucumber` `Allure` |
| **3** | [**Главный пульт управления**](./Control-Panel/) | Интерактивная симуляция промышленного/космического пульта со сложной логикой состояний и звуковым сопровождением. | `HTML5` `CSS3` `Vanilla JavaScript` |

##  Краткое описание проектов

### 1.  Крестики-нолики (Fullstack Web)
Классическая игра, переосмысленная в уникальном «древнерусском» визуальном стиле (кастомные иконки, анимированный курсор).
**Ключевые особенности:**
* **Архитектура:** Многослойная (Web, Domain, Datasource) с использованием Spring DI.
* **Бэкенд:** REST API, Spring Boot, JPA/Hibernate, PostgreSQL.
* **Функционал:** Регистрация/вход (Basic Auth), режимы PvP и PvE (AI на алгоритме Minimax), сохранение истории игр, Polling для обновления состояния в реальном времени.
* **Статусы:** Ожидание, процесс, победа X/O, ничья.

 *[Подробная документация и инструкции по запуску](./Tic-Tac-Toe/README.md)*

---

### 2.  UI Web Testing / AQA
Проект по автоматизации тестирования интернет-магазина [SauceDemo](https://www.saucedemo.com/). Включает сравнение ручного написания кода и генерации с помощью ИИ.
**Ключевые особенности:**
* **Подходы:** Паттерн **Page Object**, BDD-тестирование с использованием синтаксиса **Gherkin** (Cucumber).
* **Инструменты:** Selenide (для избавления от `Thread.sleep` и встроенных ожиданий), JUnit 5.
* **Отчетность:** Интеграция с **Allure** (автосбор скриншотов, page source и логов при падениях).
* **Покрытие:** Авторизация, работа с каталогом, корзина и оформление заказа (позитивные и негативные сценарии).

 *[Подробная документация и команды Gradle](./AQA-UI-Testing/README.md)*

### 3. 🎛 Главный пульт управления (Frontend Simulation)
Интерактивная панель управления, симулирующая работу космического или промышленного пульта. Демонстрирует глубокое понимание работы с DOM, событиями и состояниями на чистом JS.
**Ключевые особенности:**
* **Сложная логика:** Динамическое изменение температуры в зависимости от мощности двигателя, фазы нагрева/остывания и целевых диапазонов.
* **Состояния и блокировки:** Автопилот (блокировка ползунка), Аварийный стоп (сброс систем), открытие шлюза (только при выключенном двигателе).
* **UI/UX:** Визуализация перегрева (изменение цвета и свечения текста), системные уведомления (success/warning/error) с защитой от спама.
* **Мультимедиа:** Звуковое сопровождение событий (запуск двигателя, аварийный стоп, движение ползунков) с учетом политик автозапуска браузеров.

 *[Подробная документация и таблица состояний](./Control-Panel/README.md)*

##  Навыки, продемонстрированные в проектах

* **Backend & Architecture:** Spring Boot, REST API, JPA/Hibernate, PostgreSQL, многослойная архитектура, Dependency Injection.
* **Testing & QA:** AQA, Selenide, Cucumber (BDD/Gherkin), JUnit 5, Allure, Page Object Pattern.
* **Frontend & Logic:** Vanilla JavaScript, DOM API, обработка событий, работа с аудио/визуальными эффектами, алгоритм Minimax.
* **Tools:** Gradle, Git, Basic Auth, UUID.
